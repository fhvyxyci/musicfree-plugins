# MusicFree 插件订阅源

这个仓库只放一份**订阅清单**（`plugins.json`），不存放插件本体。插件文件在各自主仓库里发布，这里只记录它们的最新地址与版本。

另外收了一份[《用 AI 做同类网盘插件的提示词》](./PROMPT.md)——两个插件都是照它做出来的，里面还记了第二个插件踩出来的坑。

| 插件 | 版本 | 需要填什么 |
| --- | --- | --- |
| **蓝奏云** | 0.0.16 | 账号 + 密码（可选填 Cookie 兜底） |
| **阿里云盘** | 0.0.8 | 刷新令牌 refresh_token |

两个插件都是「把网盘当音乐库」：全盘搜索、把音乐目录下的文件夹当歌单/专辑、按目录浏览、递归汇总全部歌曲、播放直链、自动找同目录同名 `.lrc` 歌词、读文件内嵌标签。

## 桌面版

1. **插件管理 → 订阅设置**
2. 点「添加」，备注随意（比如 `fhvyxyci`），链接填上面那条
3. 「保存」
4. 回到插件管理页，点 **更新订阅**

## 手机版（支持订阅源的新版本）

1. **插件管理 → 右上角三个点 → 订阅源管理**
2. 添加订阅源，链接填上面那条
3. 返回插件管理 → **右上角三个点 → 同步订阅源**

同步后两个插件会一起装上；以后想更新，再点一次「同步订阅源」即可。

> 旧版手机端没有订阅源功能，只能在「从网络安装」里逐个粘插件地址：
> - `https://fhvyxyci.github.io/musicfree-plugin-lanzou/lanzou.js`
> - `https://fhvyxyci.github.io/musicfree-plugin-aliyundrive/aliyundrive.js`

## 订阅清单格式

给想自己搭订阅源的人参考，格式就是这样一份 JSON：

```json
{
  "name": "订阅源名称",
  "updatedAt": "2026-11-20T16:48:00+08:00",
  "plugins": [
    {
      "name": "蓝奏云",
      "platform": "蓝奏云",
      "version": "0.0.16",
      "author": "fhvyxyci",
      "description": "一句话说明",
      "url": "插件 .js 的直链",
      "source": "插件源码仓库地址"
    }
  ]
}
```

要点：

- 顶层是 `plugins` 数组，**每一项的 `url` 才是真正被安装的地址**，必须是可匿名访问的 `.js` 直链
- `name` / `platform` / `version` / `author` / `description` / `source` 都是给人看的，客户端不解析
- 想加插件就往数组里追一项，不用改别的地方

## 关于更新

- 插件本体在各自的仓库里发布，这个清单里的 `url` 直接指向它们的发布地址——所以**你同步订阅源拿到的永远是最新文件**，这份清单滞后最多只影响表格里的版本号和说明
- 各插件的文档、更新日志、issue 请到对应仓库：
  - 蓝奏云：https://github.com/fhvyxyci/musicfree-plugin-lanzou
